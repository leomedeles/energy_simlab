# Live Technology Tree

## Purpose

This document records the capabilities currently demonstrated by the system, their evidence-backed maturity and the nearby learning frontier revealed by the latest validated work.

It is not a fixed roadmap. Proposed nodes are non-binding candidates and may be changed, combined, reordered, replaced or discarded.

## Update rules

1. Only validated capabilities may be marked unlocked.
2. Every unlocked capability links to evidence.
3. Proposals originate from the current implemented system and revealed gaps.
4. Proposals must point in a direction compatible with `NORTH_STAR.md`.
5. Proposed nodes do not contain frozen implementation plans.
6. Selection begins a separate charter, research and specification cycle.
7. The developer updates this file only after validated integration or when starting an approved active node.
8. Obsolete proposals are removed or replaced rather than accumulated indefinitely.
